# 最小活动版本包含什么

本仓库只保留实现扩展画幅所需的**最小活动功能**，不按中间调试版本展开。

## 扩展画幅

- 自定义模型 **4..6**（2:1、2.35:1、XPan 等；具体比例由 CP 手动记录决定）；
- 原生 `52b` 保存 4..6，菜单增加自定义画幅行；
- CP 手动比例记录和消费路径，覆盖取景、对焦放大、拍摄、回放；
- AP 为普通取景、MF、拍摄、回放分别提供独立几何/上下文；
- RAW 保留原厂全源；大预览使用独立 1920 宽；
- 照片输出独立源查询；共享源查询恢复原语义；
- 不做 Sony 全内部枚举扩展，只在审计过的路径兼容。

## 使用扩展画幅所必需的重启/显示修复

- 菜单资源/文字查询限制到全传感器资源，避免只支持 0..3 的原版断言；
- AF 可移动边界、框 glyph 偏移、FC/YUV、CWB、自动布局五个四项域；
- NONE/全 AUTO 零矩形校准；小窗双向适配；
- 规则 NOT_SET 保护；
- 图标枚举、set_still_format 源格式、网格/菜单 getter；
- MP tracking frame、MP AF window 源类别；
- MF/回放共用 PID3019 源画幅输入；
- 菜单所有权守卫、回放表交接、规则兼容；
- CP selector 缺键 generic3、BOOT1 局部上下文。

这些修复是使用自定义画幅时不重启/不进入错误显示所必需的。

## 关闭的调试

- 5 个有界异常记录器钩子（assert/fatal/request/set/sequence）恢复为原版指令；
- AF RAM 观察器钩子恢复为原版指令；
- 这些调试不是扩展画幅的必要条件；关闭后不产生调试文件 IO；
- 基础镜像中的死代码仍在，但不再被调用；完整删除死代码需要重新链接，本仓库未提供。

## 不包含

- 与扩展画幅无关的 AF 框修正；AF 框行为保持基础项目最后功能基线；
- RAW 放大/弹窗探针、读取/回放/回归脚本；
- Sony 原厂固件、DAT、升级器、密钥。

## 已知限制

- 自定义画幅菜单文字/图标仍复用全传感器资源；
- MPR 容量估算保守，可能低报；
- 没有扩展 Sony 的所有内部枚举；
- AF 框修正不在本最小版本内；
- 调试死代码未完整删除；
- 离线回归不是物理像素验收。

## 版本号

本仓库不分配自己的版本号。打包时固件版本字段只是**容器编号**，填任意比机内当前版本更新的编号即可；最终 AP/CP 内容哈希固定，DAT 哈希随编号变化。
